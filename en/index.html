Frequently Asked Questions

Quickly find the answers you need

Will image compression affect image quality?

Our intelligent compression algorithm maximizes file size reduction while maintaining visual quality. We recommend using 70% settings, which can significantly reduce file size while maintaining good image quality.

What image formats are supported?

We support three mainstream formats: JPEG, PNG, and WebP. JPEG is suitable for photos, PNG for transparent images, and WebP provides the best compression effect.

Will my images be uploaded to servers?

No! All processing is done locally in your browser, image data never leaves your device, completely protecting your privacy and security.

How to choose the best compression settings?

For general use, we recommend 70% scaling and 70% quality. If you need smaller files, you can reduce quality to 60%; if you need better quality, you can increase quality to 85%.

Can compressed images be restored to original?

Image compression is lossy compression and cannot be completely restored to the original state. We recommend backing up original images before compression, or using lower compression ratios to maintain better quality.
